---
title: "03 · Shielded pool"
description: Deposit 1 SOL, then withdraw it to a fresh address that no one can link to the deposit. Merkle paths, nullifiers, two circuits sharing a Rust crate, and an Anchor program that never hashes.
---

In this tutorial you'll build a shielded pool: anyone deposits a fixed amount, and later
withdraws it to a new address. Onchain, an observer sees a deposit and, separately, a
withdrawal, with nothing to say which deposit it came from. By the end you'll have:

- a **shared crate**, `pool`: the Merkle tree of deposits, as plain Rust a wallet also runs;
- a **deposit circuit**, which proves a new tree root is the old tree with one leaf appended;
- a **withdraw circuit**, which proves you own *some* leaf, and reveals its nullifier;
- an **Anchor program** that holds the SOL, keeps recent roots and spent nullifiers, and never
  hashes anything;
- an **end-to-end test**: two deposits, then a withdrawal relayed to a fresh address, once.

## How it works

A deposit is a secret **note**: two random field elements, `nullifier` and `secret`. The depositor
keeps it, and the pool appends its **commitment**, a Poseidon2 hash of both, as the next leaf of a
Merkle tree. To withdraw, the owner proves two things without saying which leaf is theirs:

1. their commitment is a leaf of a tree whose root the program knows (a Merkle path);
2. a value only the note's owner can compute, its **nullifier hash**, is what they say it is.

The program records each nullifier hash it pays out, so a note can't be withdrawn twice. Since the
proof hides the leaf, the withdrawal could have come from any deposit in the tree.

**The chain never hashes.** A Merkle tree needs a hash, and if the program's hash and the
circuit's ever differ by a byte, the roots never match. So the program doesn't hash at all. A
deposit comes with a proof that the new root is the program's tree with one more leaf, and the
program stores that root. Every hash lives in the circuits, and they agree with the program by
construction.

For the gadgets underneath, see [Commitments & Merkle trees](/docs/gadgets/commitments) and
[Hashes](/docs/gadgets/hashes).

### Write the tree

A wallet tracks the tree as one value: the **path of the next free leaf**, its index and its
sibling at each of the tree's 20 levels. That path's root over an empty slot is the tree's root.
Its root over a new leaf is the tree's root once that leaf is appended. Replace `pool/src/lib.rs`
with:

```rust title="pool/src/lib.rs"
//! What both circuits share: a path into the Merkle tree of notes, and
//! Solana addresses as circuit inputs.
use xark::prelude::*;

/// Tree height: 2^20 notes.
pub const H: usize = 20;

/// The empty leaf, ASCII `xarkzero`: no note commitment is this value, so an
/// empty slot can't be spent.
pub const ZERO_LEAF: u64 = 0x7861_726b_7a65_726f;

/// A leaf's authentication path: its index, and its sibling at each height.
#[input]
pub struct Path {
    pub index: u32,
    pub siblings: [Field; 20],
}

#[input]
impl Path {
    /// The first leaf's path, in the empty tree.
    #[cfg(not(xark))]
    pub fn first() -> Path {
        Path { index: 0, siblings: zeros() }
    }

    /// The root of the tree with `leaf` at this path.
    pub fn root(&self, leaf: Field) -> Field {
        let bits = Field::from(self.index).to_bits::<H>();
        xark_merkle::merkle_root(leaf, self.siblings, bits)
    }

    /// For the next free leaf's path, the tree's root: the slot is still empty.
    pub fn tree_root(&self) -> Field {
        self.root(Field::from(ZERO_LEAF))
    }

    /// The next free leaf's path, once `leaf` is appended at this one.
    #[cfg(not(xark))]
    pub fn next(self, leaf: Field) -> Path {
        assert!((self.index as usize) < (1 << H) - 1, "the tree is full");
        let index = self.index + 1;
        let z = zeros();
        let mut siblings = self.siblings;
        let mut node = leaf;
        for (i, sibling) in siblings.iter_mut().enumerate() {
            let (mine, next) = (self.index >> i, index >> i);
            let old = *sibling;
            if next != mine {
                // A new subtree: its left sibling is this leaf's, its right is empty.
                *sibling = if next & 1 == 1 { node } else { z[i] };
            }
            node = node_of(mine, node, old);
        }
        Path { index, siblings }
    }

    /// This path once `leaf` lands at `later`, a later leaf's path.
    #[cfg(not(xark))]
    pub fn update(self, later: Path, leaf: Field) -> Path {
        assert!(later.index > self.index, "`later` must be a later leaf's path");
        let mut siblings = self.siblings;
        let mut node = leaf;
        for (i, (sibling, beside)) in siblings.iter_mut().zip(later.siblings).enumerate() {
            let at = later.index >> i;
            if at == self.index >> i ^ 1 {
                *sibling = node;
            }
            node = node_of(at, node, beside);
        }
        Path { index: self.index, siblings }
    }
}

/// The parent of `node`, at position `at` in its level, and its `sibling`.
#[cfg(not(xark))]
fn node_of(at: u32, node: Field, sibling: Field) -> Field {
    if at & 1 == 0 {
        xark_poseidon::hash2(node, sibling)
    } else {
        xark_poseidon::hash2(sibling, node)
    }
}

/// `zeros()[i]` is the root of an empty subtree of height `i`.
#[cfg(not(xark))]
fn zeros() -> [Field; H] {
    let mut z = [Field::from(ZERO_LEAF); H];
    for i in 1..H {
        z[i] = xark_poseidon::hash2(z[i - 1], z[i - 1]);
    }
    z
}

/// A Solana address enters a circuit as xark's `Hash`: two field elements.
pub use xark_hash::Hash;

#[cfg(test)]
mod tests {
    use super::*;
    use xark_poseidon::hash2;

    /// The root of `leaves`, hashed from scratch level by level.
    fn root_of(leaves: &[Field]) -> Field {
        let mut level = leaves.to_vec();
        let mut empty = Field::from(ZERO_LEAF);
        for _ in 0..H {
            level = level.chunks(2).map(|p| hash2(p[0], *p.get(1).unwrap_or(&empty))).collect();
            empty = hash2(empty, empty);
        }
        level.first().copied().unwrap_or(empty)
    }

    #[test]
    fn paths_agree_with_the_whole_tree() {
        let leaves: Vec<Field> = (1..=11u64).map(Field::from).collect();
        let mut tip = Path::first();
        let mut paths: Vec<Path> = Vec::new();
        for (i, &leaf) in leaves.iter().enumerate() {
            assert_eq!(tip.tree_root(), root_of(&leaves[..i]));
            paths = paths.into_iter().map(|p| p.update(tip, leaf)).collect();
            paths.push(tip);
            tip = tip.next(leaf);
            // Every leaf so far is in the current root, at its kept path.
            for (j, path) in paths.iter().enumerate() {
                assert_eq!(path.root(leaves[j]), root_of(&leaves[..=i]));
            }
        }
    }
}
```

Three things to notice:

- `root` is the one function a circuit calls. It's `xark-merkle`'s `merkle_root`, so in a circuit
  it becomes constraints, and on the host it computes the same root.
- `first`, `next` and `update` are `#[cfg(not(xark))]`: host-only Rust, for a wallet keeping its
  paths current as deposits land. They're never compiled into a circuit, so they cost nothing
  there. See [On the host](/docs/reference/language#on-the-host).
- `#[input] impl` makes the methods client functions too: the TypeScript wallet will call this
  exact code.

Add `pool` to the deposit crate:

A deposit proves one statement, its public `Append`: the program's root and next index, the new
leaf, and the root once the leaf is appended. Replace `deposit/src/lib.rs` with:

```rust title="deposit/src/lib.rs"
use pool::Path;
use xark::prelude::*;

/// What the program checks a deposit against: its tree's root and next index,
/// the new leaf, and the root once the leaf is appended. The public inputs, in
/// this order.
#[input]
pub struct Append {
    pub old_root: Field,
    pub new_root: Field,
    pub leaf: Field,
    pub index: u32,
}

#[input]
impl Append {
    /// `leaf` appended at `path`, the next free leaf's path.
    pub fn of(path: Path, leaf: Field) -> Append {
        Append {
            old_root: path.tree_root(),
            new_root: path.root(leaf),
            leaf,
            index: path.index,
        }
    }
}

#[circuit]
pub fn deposit(path: Private<Path>, append: Public<Append>) {
    require_eq(Append::of(path, append.leaf), append);
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn appends_to_the_tree() {
        let tip = Path::first().next(Field::from(7u64));
        let append = Append::of(tip, Field::from(8u64));
        deposit(tip, append).unwrap();
        // Another index, or the empty tree's root: each is refused.
        assert!(deposit(tip, Append { index: 2, ..append }).is_err());
        let empty = Path::first().tree_root();
        assert!(deposit(tip, Append { old_root: empty, ..append }).is_err());
    }
}
```

The circuit is one line: the public statement must be what `Append::of` computes from the private
path. Only the tree's true siblings hash up to the program's `old_root`, so the same siblings give
the true `new_root`. The depositor can't slip a different tree in.

The withdraw crate also hashes notes, with Poseidon2:

```sh

cd ..
```

Replace `withdraw/src/lib.rs` with:

```rust title="withdraw/src/lib.rs"
use pool::{Hash, Path};
use xark::prelude::*;
use xark_poseidon2::hash;

/// A deposit's secret: whoever knows it can withdraw the deposit, once.
#[input]
pub struct Note {
    pub nullifier: Field,
    pub secret: Field,
}

#[input]
impl Note {
    /// The leaf a deposit appends: it hides both secrets.
    pub fn commitment(&self) -> Field {
        hash(self.to_fields())
    }

    /// What a withdrawal reveals: the same every time for this note, and
    /// unlinkable to its commitment without the secret.
    pub fn nullifier_hash(&self) -> Field {
        hash([self.nullifier])
    }
}

/// What the program checks a withdrawal against: the public inputs, in this order.
#[input]
pub struct Withdrawal {
    pub root: Field,
    pub nullifier_hash: Field,
    pub recipient: Hash,
    pub relayer: Hash,
    pub fee: u64,
}

#[input]
impl Withdrawal {
    /// Withdrawing `note`, at `path`, to `recipient`, paying `fee` to `relayer`.
    pub fn of(note: Note, path: Path, recipient: Hash, relayer: Hash, fee: u64) -> Withdrawal {
        Withdrawal {
            root: path.root(note.commitment()),
            nullifier_hash: note.nullifier_hash(),
            recipient,
            relayer,
            fee,
        }
    }
}

#[circuit]
pub fn withdraw(note: Private<Note>, path: Private<Path>, withdrawal: Public<Withdrawal>) {
    // The note is in the tree, and this is its nullifier hash.
    require_eq(path.root(note.commitment()), withdrawal.root);
    require_eq(note.nullifier_hash(), withdrawal.nullifier_hash);
    // Nothing else uses the addresses, so bind them: the proof pays only them.
    bind(withdrawal.recipient);
    bind(withdrawal.relayer);
}

#[cfg(test)]
mod tests {
    use super::*;

    fn note(n: u64) -> Note {
        Note { nullifier: Field::from(n), secret: Field::from(n + 1000) }
    }

    #[test]
    fn withdraws_a_note_in_the_tree() {
        let (mine, theirs) = (note(1), note(2));
        // I deposit, then they do: my path changes with their deposit.
        let path = Path::first();
        let tip = path.next(mine.commitment());
        let path = path.update(tip, theirs.commitment());
        let root = tip.next(theirs.commitment()).tree_root();

        let ok = Withdrawal::of(mine, path, [1; 32].into(), [2; 32].into(), 5);
        assert_eq!(ok.root, root);
        withdraw(mine, path, ok).unwrap();
        // Their note at my path, or a root my note isn't in: refused.
        let theirs_here = Withdrawal { nullifier_hash: theirs.nullifier_hash(), ..ok };
        assert!(withdraw(theirs, path, theirs_here).is_err());
        let stale = Withdrawal { root: tip.tree_root(), ..ok };
        assert!(withdraw(mine, path, stale).is_err());
    }
}
```

`recipient`, `relayer` and `fee` are public inputs the program fills in from the transaction, so
whoever submits the proof can't redirect the payout. The two addresses are only bound, as the
holder was in [02](/docs/tutorials/02-zkyc). `fee` is a `u64`, and its range check
already uses it.

```ts title="app/shielded-pool.test.ts"
import { readFileSync } from "node:fs";
import { beforeAll, expect, test } from "vitest";
import { Append, Deposit, Path, type DepositProver } from "./deposit";
import { Field, Note, Withdraw, Withdrawal, type WithdrawProver } from "./withdraw";

/** What `xark build`, `xark setup` and `xark client` wrote for circuit `name`. */
function files(name: string) {
  const out = `../${name}/target/xark/${name}/`;
  const read = (file: string) => new Uint8Array(readFileSync(out + file));
  return {
    circuit: read("circuit.xbc"),
    provingKey: read("pk.bin"),
    sources: readFileSync(out + "sources.json", "utf8"),
    client: read("client.wasm"),
  };
}

let deposits: DepositProver;
let withdrawals: WithdrawProver;
beforeAll(async () => {
  deposits = await Deposit.prover(files("deposit"), { digest: Deposit.digest });
  withdrawals = await Withdraw.prover(files("withdraw"), { digest: Withdraw.digest });
});

/** A fresh note: two random field elements, kept secret by the depositor. */
const newNote = (): Note => ({
  nullifier: new Field(crypto.getRandomValues(new Uint8Array(31))),
  secret: new Field(crypto.getRandomValues(new Uint8Array(31))),
});

test("a wallet keeps its path as others deposit", () => {
  const [mine, theirs] = [newNote(), newNote()];
  let tip = Path.first(); // the empty tree's next free leaf
  let path = tip; // my note lands here
  tip = tip.next(Note.commitment(mine));
  // They deposit after me: my path changes beside theirs.
  path = path.update(tip, Note.commitment(theirs));
  tip = tip.next(Note.commitment(theirs));

  const zero = new Uint8Array(32);
  const withdrawal = Withdrawal.of(mine, path, zero, zero, 0);
  expect(withdrawal.root).toEqual(tip.treeRoot());
  withdrawals.prove({ note: mine, path, withdrawal });

  // A note that isn't in the tree has no proof.
  const stranger = newNote();
  const theirClaim = { ...Withdrawal.of(stranger, path, zero, zero, 0), root: tip.treeRoot() };
  expect(() => withdrawals.prove({ note: stranger, path, withdrawal: theirClaim })).toThrow(
    /path\.root\(note\.commitment\(\)\)/,
  );
}, 60_000);
```

This is the wallet: `Path.first`, `next` and `update` are the Rust from `pool`, so the paths the
wallet keeps can't disagree with the circuits. `deposits` is for the onchain test at the end.

The program has three instructions:

- `initialize(denomination)` creates a pool for one amount, at a PDA seeded by that amount. One
  program serves 0.1, 1 or 10 SOL pools side by side, and every note in a pool is worth the same.
- `deposit(commitment, new_root, proof)` checks the proof against its own root and next index,
  takes the denomination, and stores `new_root`.
- `withdraw(proof, root, nullifier_hash, fee)` checks that `root` is one of its 16 most recent
  roots, checks the proof against the recipient and relayer accounts, creates a PDA for the
  nullifier hash and pays out. A second withdrawal of the same note fails creating that PDA.

Replace `program/src/lib.rs` with:

```rust title="program/src/lib.rs"
use anchor_lang::prelude::*;
use anchor_lang::system_program;
use deposit_verifier::Proof; // the same type in both verifier crates

declare_id!("Fg6PaFpoGXkYsidMpWTK6W2BeZ7FEfcYkg476zPFsLnS");

const TREE_HEIGHT: u32 = 20;
const ROOT_HISTORY_SIZE: usize = 16;

// The empty tree's root, little-endian: `Path.first().treeRoot()`. Fixed here so
// a pool can't be seeded with another tree.
const EMPTY_ROOT: [u8; 32] = [
    26, 122, 47, 146, 164, 115, 191, 166, 88, 234, 28, 252, 38, 169, 221, 171, 246, 159, 204, 103,
    2, 229, 199, 103, 212, 104, 254, 41, 151, 59, 127, 46,
];

#[program]
pub mod shielded_pool {
    use super::*;

    /// Create the pool for one denomination.
    pub fn initialize(ctx: Context<Initialize>, denomination: u64) -> Result<()> {
        let pool = &mut ctx.accounts.pool;
        pool.denomination = denomination;
        pool.roots[0] = EMPTY_ROOT;
        pool.bump = ctx.bumps.pool;
        Ok(())
    }

    /// Deposit the denomination and append `commitment`. The proof says
    /// `new_root` is the current tree with `commitment` appended.
    pub fn deposit(
        ctx: Context<Deposit>,
        commitment: [u8; 32],
        new_root: [u8; 32],
        proof: [u8; 256],
    ) -> Result<()> {
        let pool = &ctx.accounts.pool;
        require!(pool.next_index < 1 << TREE_HEIGHT, PoolError::TreeFull);

        // The deposit circuit's public `Append`, field by field.
        let public_inputs = [
            pool.current_root(),
            new_root,
            commitment,
            field_from_u64(pool.next_index as u64),
        ];
        require!(
            deposit_verifier::verify(&Proof::from_le_bytes(&proof), &public_inputs),
            PoolError::InvalidProof
        );

        system_program::transfer(
            CpiContext::new(
                ctx.accounts.system_program.key(),
                system_program::Transfer {
                    from: ctx.accounts.depositor.to_account_info(),
                    to: ctx.accounts.pool.to_account_info(),
                },
            ),
            pool.denomination,
        )?;
        let index = ctx.accounts.pool.next_index;
        ctx.accounts.pool.push_root(new_root);
        emit!(DepositEvent { commitment, index });
        Ok(())
    }

    /// Pay the denomination, less `fee`, to `recipient`, and `fee` to the relayer.
    /// Creating the `nullifier` account fails if this note was spent before.
    pub fn withdraw(
        ctx: Context<Withdraw>,
        proof: [u8; 256],
        root: [u8; 32],
        nullifier_hash: [u8; 32],
        fee: u64,
    ) -> Result<()> {
        let pool = &ctx.accounts.pool;
        require!(fee <= pool.denomination, PoolError::FeeTooHigh);
        require!(pool.knows_root(&root), PoolError::UnknownRoot);

        // The withdraw circuit's public `Withdrawal`, field by field.
        let [r_hi, r_lo] = address_halves(&ctx.accounts.recipient.key());
        let [l_hi, l_lo] = address_halves(&ctx.accounts.relayer.key());
        let public_inputs = [root, nullifier_hash, r_hi, r_lo, l_hi, l_lo, field_from_u64(fee)];
        require!(
            withdraw_verifier::verify(&Proof::from_le_bytes(&proof), &public_inputs),
            PoolError::InvalidProof
        );

        let denomination = pool.denomination;
        **ctx.accounts.pool.to_account_info().try_borrow_mut_lamports()? -= denomination;
        **ctx.accounts.recipient.try_borrow_mut_lamports()? += denomination - fee;
        **ctx.accounts.relayer.try_borrow_mut_lamports()? += fee;
        Ok(())
    }
}

#[derive(Accounts)]
#[instruction(denomination: u64)]
pub struct Initialize<'info> {
    #[account(
        init,
        payer = authority,
        space = 8 + Pool::INIT_SPACE,
        seeds = [b"pool", denomination.to_le_bytes().as_ref()],
        bump
    )]
    pub pool: Box<Account<'info, Pool>>,
    #[account(mut)]
    pub authority: Signer<'info>,
    pub system_program: Program<'info, System>,
}

#[derive(Accounts)]
pub struct Deposit<'info> {
    #[account(mut, seeds = [b"pool", pool.denomination.to_le_bytes().as_ref()], bump = pool.bump)]
    pub pool: Box<Account<'info, Pool>>,
    #[account(mut)]
    pub depositor: Signer<'info>,
    pub system_program: Program<'info, System>,
}

#[derive(Accounts)]
#[instruction(proof: [u8; 256], root: [u8; 32], nullifier_hash: [u8; 32])]
pub struct Withdraw<'info> {
    #[account(mut, seeds = [b"pool", pool.denomination.to_le_bytes().as_ref()], bump = pool.bump)]
    pub pool: Box<Account<'info, Pool>>,
    #[account(
        init,
        payer = relayer,
        space = 8,
        seeds = [b"nullifier", pool.denomination.to_le_bytes().as_ref(), nullifier_hash.as_ref()],
        bump
    )]
    pub nullifier: Account<'info, Nullifier>,
    /// CHECK: only receives lamports; the proof binds its address.
    #[account(mut)]
    pub recipient: UncheckedAccount<'info>,
    #[account(mut)]
    pub relayer: Signer<'info>,
    pub system_program: Program<'info, System>,
}

#[account]
#[derive(InitSpace)]
pub struct Pool {
    pub denomination: u64,
    pub next_index: u32,
    pub current_root_index: u32,
    pub roots: [[u8; 32]; ROOT_HISTORY_SIZE],
    pub bump: u8,
}

impl Pool {
    fn current_root(&self) -> [u8; 32] {
        self.roots[self.current_root_index as usize]
    }

    /// Remember `root` as the newest in the ring, and advance the tree.
    fn push_root(&mut self, root: [u8; 32]) {
        self.current_root_index = (self.current_root_index + 1) % ROOT_HISTORY_SIZE as u32;
        self.roots[self.current_root_index as usize] = root;
        self.next_index += 1;
    }

    /// One of the recent roots. The ring's unused slots are zero; no root is.
    fn knows_root(&self, root: &[u8; 32]) -> bool {
        root != &[0; 32] && self.roots.contains(root)
    }
}

#[account]
pub struct Nullifier {}

#[event]
pub struct DepositEvent {
    pub commitment: [u8; 32],
    pub index: u32,
}

#[error_code]
pub enum PoolError {
    #[msg("invalid proof")]
    InvalidProof,
    #[msg("unknown or stale merkle root")]
    UnknownRoot,
    #[msg("fee exceeds denomination")]
    FeeTooHigh,
    #[msg("tree is full")]
    TreeFull,
}

/// A u64 as a 32-byte little-endian field element.
fn field_from_u64(x: u64) -> [u8; 32] {
    let mut out = [0u8; 32];
    out[..8].copy_from_slice(&x.to_le_bytes());
    out
}

/// An address as the circuit's `Hash`: `[hi, lo]`, each 16-byte half read as a
/// big-endian integer, as 32-byte little-endian field elements.
fn address_halves(address: &Pubkey) -> [[u8; 32]; 2] {
    let bytes = address.to_bytes();
    let half = |b: &[u8]| {
        let mut out = [0u8; 32];
        out[..16].copy_from_slice(b);
        out[..16].reverse();
        out
    };
    [half(&bytes[..16]), half(&bytes[16..])]
}
```

There's no hash anywhere in it. `EMPTY_ROOT` is the one tree value the program holds itself, and
the test in the next step checks it against `Path.first().treeRoot()`. The program reads every
other public input from its own state (`current_root`, `next_index`) or from the transaction (the
recipient's and relayer's addresses), so a proof only holds for this pool, now, paying these
accounts. `DepositEvent` is how a wallet learns of other deposits, to call `update` on its paths.

```ts title="app/shielded-pool.test.ts"
// Send `instruction` in one transaction, paid by `payer`. Throws with the
// program's logs if it fails.
async function send(svm: LiteSVM, payer: KeyPairSigner, instruction: Instruction) {
  const tx = await pipe(
    createTransactionMessage({ version: 0 }),
    (m) => setTransactionMessageFeePayerSigner(payer, m),
    (m) => setTransactionMessageLifetimeUsingBlockhash({ blockhash: svm.latestBlockhash(), lastValidBlockHeight: 0n }, m),
    (m) => appendTransactionMessageInstruction(instruction, m),
    (m) => signTransactionMessageWithSigners(m),
  );
  const result = svm.sendTransaction(tx);
  svm.expireBlockhash();
  if (result instanceof FailedTransactionMetadata) {
    throw new Error(`transaction failed: ${result.err()}\n${result.meta().logs().join("\n")}`);
  }
  return result.computeUnitsConsumed();
}

// An Anchor instruction's data: sha256("global:<name>")[..8], then the arguments.
const anchorData = (name: string, ...args: Uint8Array[]) =>
  new Uint8Array(Buffer.concat([createHash("sha256").update(`global:${name}`).digest().subarray(0, 8), ...args]));

// A u64, little-endian, as Anchor's arguments and the PDA seeds have it.
function u64le(x: bigint) {
  const out = new Uint8Array(8);
  new DataView(out.buffer).setBigUint64(0, x, true);
  return out;
}
```

```ts title="app/shielded-pool.test.ts"
test("deposit, someone else deposits, withdraw through a relayer, once", async () => {
  const svm = new LiteSVM();
  const program = address("Fg6PaFpoGXkYsidMpWTK6W2BeZ7FEfcYkg476zPFsLnS");
  svm.addProgramFromFile(program, "../program/target/deploy/shielded_pool.so");
  const system = { address: address("11111111111111111111111111111111"), role: AccountRole.READONLY };
  const writable = (a: Address) => ({ address: a, role: AccountRole.WRITABLE });
  const signer = (s: KeyPairSigner) => ({ address: s.address, role: AccountRole.WRITABLE_SIGNER, signer: s });
  const funded = async (sol: bigint) => {
    const s = await generateKeyPairSigner();
    svm.airdrop(s.address, lamports(sol * 1_000_000_000n));
    return s;
  };
  const bytes = (a: Address) => new Uint8Array(getAddressEncoder().encode(a));

  // A pool of 1 SOL notes. Its empty root is the circuit's.
  const DENOMINATION = 1_000_000_000n;
  const [pool] = await getProgramDerivedAddress({ programAddress: program, seeds: ["pool", u64le(DENOMINATION)] });
  const authority = await funded(10n);
  await send(svm, authority, {
    programAddress: program,
    accounts: [writable(pool), signer(authority), system],
    data: anchorData("initialize", u64le(DENOMINATION)),
  });
  let tip = Path.first();
  const account = svm.getAccount(pool);
  expect(account.exists && account.data.subarray(24, 56)).toEqual(tip.treeRoot().toBytes());

  // Deposit `note` at the next free leaf, and move the tip past it.
  async function deposit(note: Note) {
    const leaf = Note.commitment(note);
    const append = Append.of(tip, leaf);
    const proof = deposits.prove({ path: tip, append });
    const depositor = await funded(10n);
    const units = await send(svm, depositor, {
      programAddress: program,
      accounts: [writable(pool), signer(depositor), system],
      data: anchorData("deposit", leaf.toBytes(), append.newRoot.toBytes(), proof.toBytes()),
    });
    console.log(`deposit ${append.index} verified onchain in ${units} CU`);
    const path = tip;
    tip = tip.next(leaf);
    return { path, leaf };
  }

  const mine = newNote();
  let { path } = await deposit(mine);
  // Someone deposits after me: my wallet updates my path.
  const later = tip;
  const { leaf } = await deposit(newNote());
  path = path.update(later, leaf);

  // A relayer submits my withdrawal to a fresh address, for a fee.
  const relayer = await funded(10n);
  const recipient = (await generateKeyPairSigner()).address;
  const fee = 10_000_000n;
  const statement = Withdrawal.of(mine, path, bytes(recipient), bytes(relayer.address), fee);
  const proof = withdrawals.prove({ note: mine, path, withdrawal: statement });
  const { root, nullifierHash } = statement;
  const [nullifier] = await getProgramDerivedAddress({
    programAddress: program,
    seeds: ["nullifier", u64le(DENOMINATION), nullifierHash.toBytes()],
  });
  const withdraw = (to: Address) => ({
    programAddress: program,
    accounts: [writable(pool), writable(nullifier), writable(to), signer(relayer), system],
    data: anchorData("withdraw", proof.toBytes(), root.toBytes(), nullifierHash.toBytes(), u64le(fee)),
  });

  // The proof pays only the recipient it was made for.
  const thief = (await generateKeyPairSigner()).address;
  await expect(send(svm, relayer, withdraw(thief))).rejects.toThrow(/InvalidProof/);

  const units = await send(svm, relayer, withdraw(recipient));
  console.log(`withdrawal verified onchain in ${units} CU`);
  expect(svm.getBalance(recipient)).toBe(DENOMINATION - fee);

  // The nullifier is spent: the same note can't come out twice.
  await expect(send(svm, relayer, withdraw(recipient))).rejects.toThrow(/already in use/);
}, 60_000);
```

## What you built

A shielded pool: 1 SOL went in from one wallet and came out at another, and nothing onchain links
the two. The new ideas:

- **Merkle paths.** A deposit's commitment is a leaf; a withdrawal proves the note behind *some*
  leaf is yours, against a root the program remembers. Every deposit in the tree is a candidate,
  so the anonymity set is the whole pool.
- **Nullifiers.** Each note has one nullifier hash. The program records it as a PDA, so a note
  pays out once, and the hash reveals nothing about which commitment it belongs to.
- **A crate shared by two circuits and a wallet.** `pool` is ordinary Rust. Both circuits compile
  its `Path::root` into constraints, and the TypeScript wallet runs its `first`, `next` and
  `update` through the generated clients.
- **The chain never hashes.** The deposit circuit proves the new root, so the program stores roots
  and verifies proofs, and the circuits and the chain can't disagree about a hash.
- **An Anchor program** around the generated verifier crates, with PDAs for pools and nullifiers.

The pool hides *which* deposit a withdrawal spends, not *how much*: every note in a pool is the
same size. It also can't hide timing. A withdrawal right after the only deposit links them anyway.
A deposit proof binds the current root and next index, so two deposits racing for the same slot
can't both land: a real wallet reads the pool's state just before proving, and proves again if
another deposit wins.
